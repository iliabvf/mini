A small English chatbot trained from scratch. It is a decoder-only transformer, not a general-purpose assistant.

GitHub Pages can show this page. It cannot run the PyTorch model, so the live chat stays on your computer.

Run the chat

pip install -r requirements.txt
python serve.py

Then open http://127.0.0.1:8765. The window uses the GPU when CUDA is available.
